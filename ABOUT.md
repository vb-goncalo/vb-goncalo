## 🧭 My path

I've always wanted to understand how systems work underneath, and how they fail.

Today I study **Network and Computer Systems Engineering** with a focus on **cybersecurity and cloud security**. Alongside my degree I build my own software: a local voice assistant for macOS, desktop utilities and projects for clients.

My goal is to build a solid foundation in **cloud security, infrastructure as code and network defense**, and to bring that security mindset to everything I build.

## 🔐 Secure by design

How I approach a project, from idea to production:

```text
🔎 RECON          understand the problem and the attack surface
   ↓
📐 DESIGN         segmentation, least privilege, threat model
   ↓
💻 BUILD          code and infrastructure as code
   ↓
🛡️ HARDEN         secrets, IAM, firewall, dependencies
   ↓
🧪 TEST           linters, scanners, try to break it
   ↓
🚀 DEPLOY         reproducible and automated
   ↓
📡 MONITOR        logs, alerts, iterate
```
